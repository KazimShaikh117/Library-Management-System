# Library Management System

A mini-project designed to demonstrate a simple Library Management System using web technologies.

## Technologies Used
HTML
CSS
JavaScript
## Project Structure
index.html – Main webpage
style.css – Styling and layout
script.js – JavaScript functionality
## Getting Started
Clone or download this repository.
Open index.html in your web browser.
Explore the project interface.
## Purpose

This project serves as a learning resource for practicing frontend development and building a basic library management interface.
